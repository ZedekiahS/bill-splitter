# 草稿、完整导出与归档复核

完成原计划第 4、5 项。数据和导出格式固定，账本标题与用途自由填写。
页面沿用现有中文/英文界面，仅增加任务所需的草稿状态、归档状态及操作确认。

## 已实现

- 输入时保存原始未完成字段、比例/金额/逐项分摊、备注和附件；普通账单、
  更正、模板、周期确认分别恢复。账号、账本和编辑对象隔离。
- 关闭、刷新后继续填写；保存成功清理对应草稿，失败保留。相同提交的请求键
  一并持久化。并发标签页采用版本比较，禁止覆盖或删除更新的草稿。
- 存储不可用时明确提示。清空已输入内容也保存清空结果；后续输入不会把
  存储失败提示覆盖成虚假的保存中状态。
- CSV / JSON / ZIP 导出，包含撤销记录、更正前后历史、周期模板和历史附件。
  ZIP 使用顺序读取附件的流，附格式与单位说明，排除邀请和身份凭据。
- 创建者归档/恢复；所有成员只读及导出，写入限制在服务端事务内执行。
  归档不清欠款，恢复后周期待确认项重新出现。

## 浏览器实测

使用独立本地测试库、创建者与成员两个账号，分别在独立域名会话操作：

1. 创建者填写 800 元住宿，自己承担 500 元、另一人留空，添加备注和图片。
   直接刷新、重开后原始金额、空白、备注、图片均恢复。
2. 补齐另一人的 300 元并保存，草稿列表为空，账本只有一笔 800 元住宿。
3. 成员填写 60 元早餐但不提交；创建者归档后，其保存被后端拒绝，输入及
   草稿保留。成员页面同步为只读，没有创建者的归档/恢复入口。
4. 成员在归档状态可下载完整 ZIP。创建者恢复后，成员无需刷新即出现继续
   填写入口；恢复早餐草稿并提交成功，账单列表为两笔，原有 300 元未被清除。
5. 创建者保存每月 120 元网费模板草稿，重新打开后恢复每月和首次日期，
   保存为模板成功。修复了恢复周期后首次日期控件没有同步显示的问题。
6. 通过真实下载按钮取得 ZIP，独立解压核对 11 个条目；金额为 80000 分，
   备注准确，PNG 与上传文件逐字节相同。
7. 检查 390×844 手机尺寸工具栏、账单页和导出对话框，无横向溢出；英文导出
   入口及按钮翻译正常，用户自定义标题原样保留。

## 验证边界

这是本地真实后端和独立浏览器会话验证，不是公网或两台物理设备的网络测试。
草稿仅属于当前设备/站点浏览器存储，不跨设备同步；清除站点数据将丢失草稿。
新增隔离/冲突/配额边界主要由自动测试验证。最后的清空字段修复经代码检查，
浏览器连接失效后未重复执行该单一场景。没有执行公网部署或导入恢复。
