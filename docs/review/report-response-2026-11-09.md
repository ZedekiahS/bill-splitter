# 迟到报告响应修复 — 2026-11-09

针对 `5d3e8d8` 复核中的两条 P3 时序问题：范围保存完成后，旧报告会短暂恢复旧勾选；离开再返回个人页后，旧同步可能覆盖新报告金额。

## 修复

- 增加独立的报告递增序号。页面重绘、统计范围保存开始和结束时使此前的报告响应失效。
- 后台同步在提交页面状态和同步修订号之前核对序号。过期响应不重绘，也不提前消耗待处理更新。
- 普通报告加载的成功与错误响应也核对序号、账号和目标节点，避免旧错误覆盖当前界面。
- 保持现有保存结束后的同步唤醒、筛选焦点、日期输入保护及阅读位置恢复方式。
