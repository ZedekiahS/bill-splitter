# 局域网验收准备与草稿补测

- 新增只绑定指定私有 IPv4 的测试启动脚本，必须使用回环地址的独立 `_test`
  数据库。保持正式启动配置不变，没有公网发布。
- 修复局域网 HTTP 没有 `crypto.randomUUID` 时，登录/记账请求键、草稿版本和
  操作历史无法生成 ID 的问题。复用一个 UUID v4 实现，随机源为
  `crypto.getRandomValues`，不使用 `Math.random`。
- 183 项本地测试、41 项 PostgreSQL/API 测试通过；新增用仅保留
  `getRandomValues` 的环境验证请求、草稿及历史 ID。
- 在电脑浏览器使用实际局域网 IP 登录成功。补测“填写标题→全部清空→关闭→
  刷新→重新打开”，显示已恢复草稿且标题仍为空，未恢复旧输入。
- 随后通过同一 HTTP 地址保存 80 元午餐成功，两人各 40 元，供手机核对。
- 测试服务已留运行供手机接入。Windows 防火墙读取权限不足，未更改防火墙，
  电脑自访可达不代表手机已可达。手机连通及物理跨设备同步仍待用户操作确认。
