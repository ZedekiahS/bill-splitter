# 连续记账与成员选择复核 · 2026-11-07

本轮对应第二轮体验修改。上一轮收款并发检查、完整备份恢复、模板草稿隔离与状态筛选修复保留。

## 最终行为

1. 保存并继续记沿用参与人、垫付人、日期和分摊方式。比例值及手动/自动意图沿用；金额、用途、备注、收据和上一笔项目不复制。按金额需重新填写金额；逐项模式创建一行空项目。
2. 姓名输入框回车复用唯一完整匹配的成员。多个同名成员展示身份及序号并要求选择；“另建同名成员”仍是明确操作。输入法组词期间回车不提交。
3. 逐项模式新增或选择已有成员后，就地选择消费项目，显示已选项数与有效分摊金额。不选择任何项目时，需明确暂不分摊才能保存。待选状态可随草稿恢复。
4. 比例行显示自动/手动状态；每个手动份额可恢复自动，其他人的手动输入不变。两人场景继续采用修改一人、另一人自动补足的规则。
5. 手机默认收起成员、身份、日期筛选，状态保持可见。生效的成员和日期显示在摘要中；折叠不改变查询条件。未选成员时身份选项禁用。
