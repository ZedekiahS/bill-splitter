# 下载日志分类复核（2026-11-16）

修复基于 `c4fbd25` 的窄范围 P3：附件查询报 `ECONNRESET` 时，不再仅凭错误代码将其归为下载连接中止。

发送流式响应时先观察源流错误，在 Fastify 的流错误日志入口按来源和响应连接状态分类：已知源流错误为 `failed`；没有源流错误且响应连接已断开为 `aborted`。保留原有去重、请求关联、安全字段过滤和实际 HTTP 状态；没有改动账务规则或产品界面。
