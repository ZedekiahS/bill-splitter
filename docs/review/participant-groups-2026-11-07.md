# 批量名单与常用组合 · 2026-11-07

第三轮范围为批量名单及命名常用组合，未加入分类、旅行汇总或还款待确认。包含前两轮的修复。

## 行为

- 记账表单内先粘贴名单，再预览已有身份、新建身份和同名候选。重复输入名称合并、可取消勾选；新建同名身份必须明确选择。预览不写数据。
- 确认时由一个服务端命令完成整批校验和写入，沿用数据库行锁及请求幂等机制。已有成员重命名、停用、移除，或预览后被别人创建的同名成员，均要求重新核对。
- 组合保存到账本，包含成员 ID，不包含金额、比例或垫付人。账本成员均可使用；创建者或管理员可编辑/删除。更新和删除校验版本。只改名保留组合成员，替换为本笔参与人是独立明确操作。
- 非逐项模式可替换或追加本笔参与人，保留自定义金额和手动比例。逐项模式明确勾选项目后追加成员，其他项目不变。
- 组合使用前重新读取并核对版本与成员状态；旧窗口不会自行把新成员加入草稿。停用成员显示但不勾选；成员被移除时清理组合引用、增加版本。删除组合不删除成员或账单。
- 输入未确认名单/未保存组合名称时，直接保存账单会定位到相关步骤，输入随本地草稿恢复。
- JSON/ZIP 导出包含组合，导入重新映射身份；旧备份缺省为空。继续使用原 JSONB 账本存储，无数据库结构迁移。

## 边界

浏览器窄屏验证不替代真机软键盘检查。合并重复名单仅去重输入文本，不合并账本身份。批量添加/组合保存立即写入共同账本，账单仍需独立保存。组合没有财务历史，不改变原账单、欠款或权限。本轮未公开部署；提交与推送按用户指示执行。
