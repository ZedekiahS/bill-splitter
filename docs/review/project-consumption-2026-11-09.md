# 项目与个人消费验收 — 2026-11-09

## 实现范围

- 并发重复删除组合返回已删除冲突，前端刷新目录并保留未保存的组合编辑。
- 原账本增加类型、可选活动日期、进行中/已结束状态。创建者设置受版本校验保护；
  结束活动仍可记账、确认收款，归档继续使用原只读规则。
- 项目总览区分总开销、本人消费与垫付；个人结算页按待付、待收分组，合并同方向
  多笔费用，展开来源；个人结算单支持复制和下载。
- 分类覆盖账单、消费条目、草稿、周期模板、历史、更正和备份。条目可继承整笔分类，
  或明确选未分类/其他分类。已发生收款的账单可更正分类而不改变金额和还款。
- 项目统计和个人消费共用按整数分计算的明细模型，按消费日期统计。趋势、分类、
  项目和成员图表可点开明细。短期项目自动按日，长期范围按月；也可手动选择粒度。
- 全局个人统计由登录身份决定，按 uid 找各账本中的本人身份；同名成员不合并。
  服务端只返回本人消费行和可访问账本目录。归档仍计入，撤销不计入，还款不计入，
  各币种分别汇总；恢复副本默认不计入，可按账号独立设置范围并跨设备保存。
